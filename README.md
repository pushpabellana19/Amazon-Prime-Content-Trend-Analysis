# Amazon Prime Video – Content Trend Analysis

## Project Overview
This project focuses on analysing the Amazon Prime Video dataset to understand content trends, genre distribution, ratings, release years, countries, and movie durations.

## Dataset
Amazon Prime Video Movies and TV Shows Dataset.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- SQLite
- SQL
- Google Colab

## Analysis Performed
1. Movies vs TV Shows Distribution
2. Top 10 Genres Analysis
3. Content Rating Distribution
4. Content Release Year Trends
5. Top 10 Countries Analysis
6. Movie Duration Analysis

## Visualizations
Created six visualizations to understand Amazon Prime Video content trends.

## SQL Analysis
Performed five SQL queries covering:
- Content Type Distribution
- Genre Analysis
- Release Year Analysis
- Country Analysis
- Content Rating Distribution

## Key Insights
- Movies represent the largest share of the catalogue.
- Drama is the most common genre.
- The United States contributes the highest number of titles among records with available country information.
- 2021 has the highest number of titles among the ten latest release years analysed.

## Deliverables
- Python EDA Notebook (.ipynb)
- SQL Queries (.sql)
- Content Strategy Memo (.pdf)

## Conclusion
This project demonstrates how Python and SQL can be used to analyse OTT streaming content and identify useful business insights.
